# 🚛 TruckersMP

**TruckersMP** is a multiplayer mod for **Euro Truck Simulator 2** and **American Truck Simulator**.  
It allows thousands of players to drive together in the same world, creating a shared and immersive trucking experience.

## 🎮 Supported Games

TruckersMP supports the following titles:

- **Euro Truck Simulator 2**
- **American Truck Simulator**

> ⚠️ An **official copy** of the game is required to play on TruckersMP.

---

## ⚙️ Requirements

To use TruckersMP, you need:

- Windows operating system  
- **.NET Framework 4.7.2** or higher  
- Supported version of ETS2 and/or ATS  
- TruckersMP Launcher  
- Active internet connection  

---

## 🧰 Features

TruckersMP provides:

- Online multiplayer with thousands of players  
- Real-time synchronization of trucks and trailers  
- Convoys and official events  
- In-game chat and CB radio  
- Player reporting and moderation system  
- Company (VTC) support  
- Dedicated event servers  

---

## 🛠️ Modifications & Save Editing

TruckersMP has **strict limitations** regarding modifications.

Allowed:
- Cosmetic accessories supported by TruckersMP  
- Official DLC content  
- Singleplayer save edits **not used online**

Not Allowed:
- Modified money, levels, or skills  
- Custom jobs or manipulated cargo  
- Physics or performance modifications  
- Any save editing that provides an unfair advantage  

Violating these rules may result in temporary or permanent bans.

---

## 🧑‍⚖️ Moderation

TruckersMP is actively moderated by a volunteer staff team.

Moderators:
- Monitor gameplay and high-traffic areas  
- Review in-game and website reports  
- Enforce rules fairly and consistently
